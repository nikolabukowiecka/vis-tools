# vis-tools
Post-processing package for GRMHD kharma and GGRT ipole for Kerr-Hayward spacetime. Workflow documentation for https://arxiv.org/abs/2604.06128.

In simulation folders there are parameter files and simulation bash scripts to reproduce our simulations. Adding actual simulation frames is not feasible due to size. Email bukowieckan@gmail.com to request them if necessary.
